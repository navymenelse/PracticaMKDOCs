# MkDocs
![logo de MkDocs](images/mkdocs.png)

## 📄 Resumen del módulo
**MkDocs** es un generador de sitios estáticos rápido, sencillo y de código abierto escrito en Python, diseñado específicamente para alojar documentación de proyectos. Funciona por completo mediante archivos Markdown y se configura con un único archivo YAML (`mkdocs.yml`). 

Combinado con el ecosistema de **Material for MkDocs**, se transforma en una potente herramienta capaz de generar webs modernas, adaptables a móviles (responsive), con soporte multilingüe, modo oscuro/claro nativo y una velocidad de carga excelente.

---

## 🎯 ¿Qué creo que aprenderé?
* A configurar de forma avanzada el archivo `mkdocs.yml` controlando la navegación multinivel, paletas de colores dinámicas y la barra de búsqueda instantánea.
* A utilizar extensiones de Markdown avanzadas compatibles con Material (como listas de tareas interactivos, bloques de código con pestañas de lenguajes y fórmulas matemáticas).
* A desplegar y compilar la documentación estática lista para producción en servidores web o plataformas cloud.

---

## 💡 ¿Qué espero de este módulo?
> Expectativa principal del módulo
