# Portafolio del Ciclo DAW - IAW

¡Bienvenido a mi sitio de documentación técnica! Este espacio recopila el desarrollo y la síntesis de los aprendizajes obtenidos a lo largo de los diferentes módulos del ciclo formativo de Desarrollo de Aplicaciones Web (DAW).

---

## 🚀 ¿Qué es MkDocs y por qué lo usamos?

<div class="grid cards" markdown>

-   **⚡ Generación Estática**
    ---
    Transforma archivos de texto plano escritos en formato Markdown en un sitio web estático optimizado, rápido y listo para producción.

-   **🛠️ Configuración Sencilla (YAML)**
    ---
    Mediante el archivo `mkdocs.yml` se gestionan de forma limpia y estructurada los metadatos, temas, extensiones y la navegación completa del sitio.

-   **🎯 Despliegue Automatizado**
    ---
    Permite una velocidad de despliegue inmediata y gratuita en plataformas de alojamiento web como GitHub Pages mediante flujos de trabajo automatizados.

</div>

---

## 🌟 Ventajas Principales

* **Facilidad de uso:** Basado en Markdown, lo que agiliza la redacción y lectura de documentación técnica[cite: 10].
* **Desarrollo en tiempo real:** Incorpora un servidor local (`mkdocs serve`) para visualizar los cambios al instante[cite: 9, 11].
* **Extensibilidad:** Compatible con una gran variedad de temas personalizables (como *Material*) y plugins avanzados[cite: 9].
