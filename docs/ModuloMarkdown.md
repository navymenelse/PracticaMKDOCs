# Módulo: Markdown
![Logo de Markdown](https://upload.wikimedia.org/wikipedia/commons/4/48/Markdown-mark.svg)

## 📄 Resumen del módulo
Markdown es un lenguaje de marcado ligero que permite aplicar formato a documentos usando un texto plano fácil de leer y escribir. El módulo se centró en conocer y dominar su sintaxis estándar y sus extensiones para hacer contenidos de forma limpia, insertar enlaces, tablas, bloques de código y elementos multimedia sin depender de procesadores de texto pesados como Microsoft Word. ya que su uso es el estándar de la industria para documentar proyectos de software y redactar archivos `README.md` en repositorios Git.

---

## 🎯 ¿Qué creo que aprenderé?
* Aprenderé la sintaxis básica y avanzada de Markdown (encabezados, listas, énfasis, tablas y bloques de código con resaltado de sintaxis), para poder estructurar documentación técnica que pueda ser procesada por generadores de sitios estáticos como MkDocs.
* Tambien aprenderé las buenas prácticas de redacción de documentación de proyectos web.

---

## 💡 ¿Qué espero de este módulo?
Espero adquirir soltura y rapidez al redactar documentación técnica limpia y profesional, entendiendo cómo este lenguaje lo puedo aprovechar para integrarme a grupos de trabajo de desarrollo y despliegue de sitios web.
